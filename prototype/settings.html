上下文规则

数学块处理
默认仅标记；MathML 转写来源的 U+2062 可能承载真实乘法语义。
ZWNJ
波斯语等语言承载构词语义，误删会毁掉复合词（#625 教训）。
代码块内空格类转普通空格
直接删除会破坏 Python 缩进与语法。

P8 标注

  1. 策略即数据：默认表逐码点三动作（清除 / 转空格 / 保留），红蓝黄分段；ZWJ 写死永久保护，不可改。
  2. 拾取追加区：FR-9 拾取的码点（如 P6 的 U+2064）追加于此，高亮显示、可改动作、可整体重置。
  3. 确认开关拆两项：全部/选区默认开（免可见强确认）；块清除默认关（免确认以检查模式为闸门）——互补规则见方案设计 §6。
  4. 语言：auto 跟随 Obsidian，手动选择覆盖；全部文案集中于 i18n.ts，en/zh 键集合一致性由单测兜底。
