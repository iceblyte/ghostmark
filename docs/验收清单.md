# Ghostmark 手动验收清单 / Manual Acceptance Checklist

对应《Ghostmark-需求分析》v1.2 §6 验收标准。自动化测试（vitest）已覆盖 §6.1–6.5 与 §6.8 的引擎部分；本清单覆盖必须在真实 Obsidian 宿主中人工核验的界面与交互项。

验证样本：仓库内 `src/core/fixtures/watermark-fixture.md`（复制进测试 vault 即可），或任意剪藏笔记。

环境：桌面端（Windows/macOS/Linux）+ 移动端（如有条件）。

## 1. 检查模式（FR-1/2/3）

- [x] 执行 "Ghostmark: 切换检查模式"（或 `Ctrl/Cmd+Alt+I`，或点击状态栏）后， fixture 中所有命中以三色行内字形呈现；再执行一次全部消失。
- [x] Source 模式与 Live Preview 下装饰均正常。
- [x] 紧凑档：红 `⌷` / 蓝 `␣`（成串显示 `␣ ×N`）/ 黄 `⌦`；设置切到"详细"后显示码点缩写（`2062`、`2002 ×20`）。
- [x] 检查模式状态对同仓库所有已打开笔记一致（无"此开彼关"）；新开笔记自动同步（含重启后，若开启"记住检查模式状态"）。
- [x] 数学块内的红字形为虚线框（仅标记）；frontmatter 标题中的 U+061C 被标记。

## 2. 悬停详情（FR-4）

- [x] 悬停成串蓝色字形：出现"空格成串（≥2）→ 整串删除"说明。

## 3. 行号槽与状态栏（FR-5/6）

- [x] 有命中的行在行号槽显示计数徽标；无命中行无徽标。
- [x] 徽标为分段式：行内每种类别一段（红/蓝/黄各带自己的数量，只显示存在的类别），
      段间以分隔线区分；整段含三类时显示三段。
- [x] 徽标不会被裁切：gutter 列宽随全文档最宽徽标自适应（如 10|32 两段、三段均可完整显示）。
- [x] 徽标悬停按情形显示三种文案：本行含可清除项 →"本行 N 处命中 · 点击清除当前块"；
      本行只有空格类（转空格）→"本行 N 处空格类 · 点击转为普通空格"；
      本行只有保留/仅标记 →"本行 N 处标记（保留/仅标记）· 无可清除项"（徽标呈半透明）。
- [x] 状态栏显示 `Ghost: 806`（fixture 全文）；随编辑即时更新；检查模式关闭时图标呈半透明。
- [x] 点击状态栏项切换检查模式。

## 7. 拾取码点（FR-9）

- [x] 建议动作按类别给出：不可见→清除、空格类→转空格、其他→保留。
- [x] 确认后 Notice 提示已加入策略表；设置 → 字符策略表 → 拾取追加区出现该行（高亮），可改动作、可单行删除、"重置为默认表"可清除。
- [x] 光标停在表内字符（如 U+2062）上执行：提示"该字符已在策略表中"。
- [x] 选区内恰好 1 个新码点 → 弹确认 Modal；多个 → 弹勾选列表（默认全选，每行显示字符/码点/类别/建议动作，点击整行即可勾选/取消，按钮实时显示"加入 N"）；全部已收录 → 回退到选区末尾字符的确认 Modal（不再出现死胡同提示）。
- [x] 编辑器内右键可见"Ghostmark: 拾取码点"菜单项。

## 11. 扩展策略表

- [x] 双向控制字符（U+202A–202E、U+2066–2069）以红色字形标记，清除全部后被移除。

- [x] 控制字符（U+000B、U+000C、U+007F、U+0085）被红色标记；制表符、换行、回车不受影响。

## 12. base64 标记与清除

- [x] 检查模式下，独立 token（44 字符、`=` 结尾）显示紫色字形（紧凑档 `⌗ ×44`，详细档 `b64 ×44`）。
- [x] 粘词 token（如 `localStorage<token>`）只标尾部 44 字符，点击清除后单词保留。
- [x] 四连发（首尾相接的 4 个 token）各自成段，可分别点击清除。
- [x] 悬停紫色字形：显示"Base64 追踪串"、段长度、类别与"点击字形可清除该段"提示。
- [x] 点击字形仅移除该段：同段其他标记与段外内容零改动，`Ctrl/Cmd+Z` 一步恢复，编辑器无滚动跳变。
- [x] 行号槽徽标出现紫色段（计数为该行 base64 字符数）；状态栏计数包含 base64。
- [x] 负例零命中：文件路径、长数字 URL、40 位十六进制哈希、短串（<20）、等号不在末尾的串。
- [x] data URI（内嵌图片）载荷不标记、清除后逐字节保留。
- [x] 代码内 token（行内代码与围栏代码块）显示虚线紫色字形，"清除全部"不触碰它们，但点击字形可清除。
- [x] "清除全部"确认弹窗出现紫色行（计数正确），执行后 Notice 含紫色计数，单步撤销完整恢复。
- [x] 设置关闭"标记 base64 乱码"后：紫色标记消失、徽标无紫色段、状态栏计数回落、清除命令不改动任何 base64；重新打开后立即恢复。

## 14. frontmatter 摘要徽标（frontmatter-summary-badge，Live Preview）

- [ ] Live Preview 下：frontmatter 含标记时，编辑器内容区上方显示"frontmatter 含 N 处标记"固定摘要条，N 为其中标记字符总数（红色 3 + base64 44 → N = 47）。
- [ ] 徽标为分段式：每类别一段、各带数量（红/紫/蓝/黄，与行号槽徽标同体系）；仅统计 frontmatter 内的命中。
- [ ] 悬停徽标显示总计数与"点击清除当前块"提示。
- [ ] 点击徽标：frontmatter 内可清除标记被单事务清理，Notice 分类计数，`Ctrl/Cmd+Z` 一步恢复；恢复后徽标重新出现。
- [ ] "块清除前确认"开启时，点击徽标先弹出确认 Modal（frontmatter 块形态），确认后执行。
- [ ] 清理后命中归零（或全部保留/仅标记且无可清除项）时徽标自动消失；base64 开关关闭时 base64 段不计入 N。
- [ ] 同一笔记切换到纯 Source 模式：徽标立即消失、frontmatter 标记以字形呈现；切回 Live Preview 徽标立即恢复。
- [ ] frontmatter 干净（或检查模式关闭）时不渲染徽标。

第二轮返工后（编辑器外固定摘要条，待复核）：

- [ ] 徽标为编辑器内容区上方的固定摘要条（不随内容滚动）；Source 模式鼠标选区、光标行为完全正常（回归确认：无跳段、无选区错位）。
- [ ] Live Preview 下 frontmatter 含标记时摘要条出现，Source 模式下消失且 frontmatter 原文与字形标记直接可见。
