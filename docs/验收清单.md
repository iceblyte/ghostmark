# Ghostmark 手动验收清单 / Manual Acceptance Checklist

对应《Ghostmark-需求分析》v1.2 §6 验收标准。自动化测试（vitest）已覆盖 §6.1–6.5 与 §6.8 的引擎部分；本清单覆盖必须在真实 Obsidian 宿主中人工核验的界面与交互项。

验证样本：仓库内 `src/core/fixtures/watermark-fixture.md`（复制进测试 vault 即可），或任意剪藏笔记。

环境：桌面端（Windows/macOS/Linux）+ 移动端（如有条件）。

## 1. 检查模式（FR-1/2/3）

- [x] 执行 "Ghostmark: 切换检查模式"（或 `Ctrl/Cmd+Alt+I`，或点击状态栏）后， fixture 中所有命中以三色行内字形呈现；再执行一次全部消失。
- [x] Source 模式与 Live Preview 下装饰均正常。
- [x] 紧凑档：红 `⌷` / 蓝 `␣`（成串显示 `␣ ×N`）/ 黄 `⌦`；设置切到"详细"后显示码点缩写（`2062`、`2002 ×20`）。
- [x] 检查模式状态对同仓库所有已打开笔记一致（无"此开彼关"）；新开笔记自动同步（含重启后，若开启"记住检查模式状态"）。
- [x] 数学块内的红字形为虚线框（仅标记）；frontmatter 标题中的 U+061C 被标记。

## 2. 悬停详情（FR-4）

- [x] 悬停红色字形：显示名称、`U+XXXX`、类别色点、"建议：清除"。
- [x] 悬停成串蓝色字形：出现"空格成串（≥2）→ 整串删除"说明。
- [x] 悬停代码块内蓝色字形：出现"转普通空格（防破坏缩进）"说明。
- [x] 悬停 ZWJ / 肤色修饰符：出现"永久保护"说明。
- [x] 数学块内字形建议动作为"仅标记"。

## 3. 行号槽与状态栏（FR-5/6）

- [x] 有命中的行在行号槽显示计数徽标；无命中行无徽标。
- [ ] 徽标为分段式：行内每种类别一段（红/蓝/黄各带自己的数量，只显示存在的类别），
      段间以分隔线区分；整段含三类时显示三段。
- [x] 徽标悬停按情形显示三种文案：本行含可清除项 →"本行 N 处命中 · 点击清除当前块"；
      本行只有空格类（转空格）→"本行 N 处空格类 · 点击转为普通空格"；
      本行只有保留/仅标记 →"本行 N 处标记（保留/仅标记）· 无可清除项"（徽标呈半透明）。
- [x] 状态栏显示 `Ghost: 806`（fixture 全文）；随编辑即时更新；检查模式关闭时图标呈半透明。
- [x] 点击状态栏项切换检查模式。

## 4. 清除全部（FR-7）

- [x] 命令弹出确认 Modal：红 324（子行 U+2062 ×108 · U+061C ×216）、蓝 477、黄 5、数学块内仅标记 3；按钮显示"清除 798"。
- [x] 执行后右上角 Notice："已清除 798 处标记（红 321 · 蓝 477）"+ 撤销提示；编辑器内装饰全部消失（黄类保留）。
- [x] `Ctrl/Cmd+Z` 一步完整恢复原文。
- [x] 设置关闭"全部 / 选区清除前确认"后不再弹窗（重开请恢复默认）。

## 5. 清除选区（FR-8）

- [x] 无选区时命令面板中"清除选区"置灰并显示"（无选区）"。
- [x] 选中含水印文字后执行：仅选区内命中被清理、选区外零改动； Modal 提示 base64 token 需手动删除。

## 6. 清除当前块（FR-13）

- [x] 光标在普通段落/列表项/引用块/表格行/代码块/数学块/frontmatter 内执行命令，仅该块被清理，块外零改动，Notice 计数正确。
- [x] 检查模式关闭时命令面板中该命令置灰并显示"（检查模式未开启）"。
- [x] 点击行号槽徽标同样触发所在块清除（同一确认规则）。
- [ ] 点击徽标清除后，编辑器停留在原浏览位置（光标映射到原位，不跳到文件开头）。
- [x] 光标在无命中块（如干净的标题行）内执行：提示"未做修改"，文本不变。
- [x] 设置开启"块清除前确认"后弹出确认 Modal（含块形态与行数说明）。

## 7. 拾取码点（FR-9）

- [x] 光标停在策略表之外字符（如 U+00AD 软连字符）上执行命令：Modal 显示码点、名称（未知显示 —）、类别色点与建议动作。
- [x] 建议动作按类别给出：不可见→清除、空格类→转空格、其他→保留。
- [x] 确认后 Notice 提示已加入策略表；设置 → 字符策略表 → 拾取追加区出现该行（高亮），可改动作、可单行删除、"重置为默认表"可清除。
- [x] 光标停在表内字符（如 U+2062）上执行：提示"该字符已在策略表中"。
- [ ] 选区内恰好 1 个新码点 → 弹确认 Modal；多个 → 弹勾选列表（默认全选，每行显示字符/码点/类别/建议动作，点击整行即可勾选/取消，按钮实时显示"加入 N"）；全部已收录 → 回退到选区末尾字符的确认 Modal（不再出现死胡同提示）。
- [ ] 编辑器内右键可见"Ghostmark: 拾取码点"菜单项。

## 8. 设置与语言（FR-11/12）

- [x] 设置四组齐全：字符策略表（21 行 + 拾取追加区）/ 上下文规则 / 界面 / 语言。
- [x] ZWJ 行锁定（下拉禁用、"写死保护"标签）；ZWNJ 行与上下文规则中 ZWNJ 联动。
- [ ] 点击红/蓝/黄分组标题进入对应子页面逐码点修改（子页面含返回键，主页面显示分组与码点数）。
- [ ] 拾取追加区顶部可手动添加码点：输入框位于整行最左，输入 U+2065 / 2065 或直接粘贴字符，动作可选（自动=按类别建议），回车或点 + 添加；已存在的码点提示"已在策略表中"。
- [ ] 拾取或修改后，已打开的设置页立即刷新显示；追加区为空时显示"尚无拾取项"提示。
- [x] 修改任意码点动作后立即生效（检查模式与清除行为同时变化）并持久化（重启 Obsidian 后保留）。
- [x] 语言切换为 English / 简体中文后：hover、Modal、Notice、设置文案全部跟随，无硬编码遗漏；"自动"跟随 Obsidian 界面语言。
- [ ] 旧版本数据（schemaVersion 1）升级后，"记住检查模式状态"自动变为开启并显示在设置页；此后手动关闭并重启仍保持关闭。

## 9. 移动端（NFR-6，如有条件）

- [ ] 检查模式装饰在移动端可用；五个命令均可在命令面板触发。
- [ ] 无状态栏项（桌面专属）；一切入口经命令面板可达。

## 10. 安全底线（NFR-1）

- [x] 清除全部后：emoji ZWJ 序列（👨‍👩‍👧‍👦、👩🏻‍💻）逐字节保留。
- [x] 默认设置下数学块未被修改。
- [x] 代码块内 U+2002 变成普通空格，无字符丢失、缩进仍在。
- [x] 文件头 BOM（若有）永不被处理。
